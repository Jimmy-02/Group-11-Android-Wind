# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone participating in the SciShare project.

We aim to create a collaborative community where individuals can share ideas, contribute knowledge, and work together constructively.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and considerate toward others.
- Communicating professionally and constructively.
- Accepting constructive feedback gracefully.
- Respecting different opinions, backgrounds, and perspectives.
- Focusing on what is best for the project and its community.
- Supporting other contributors when needed.

Examples of unacceptable behavior include:

- Harassment, discrimination, or personal attacks.
- Offensive or inappropriate comments.
- Trolling, insulting, or deliberately disruptive behavior.
- Publishing others' private information without permission.
- Any form of unprofessional or disrespectful communication.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues and discussions.
- Pull requests and code reviews.
- Project-related communications.
- Other spaces where contributors represent SciShare.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Inappropriate behavior may result in warnings, removal of contributions, or exclusion from project activities depending on the severity of the situation.

## Reporting

If you experience or witness unacceptable behavior, please contact the project maintainers through the repository's GitHub communication channels.

All reports will be reviewed respectfully and handled as confidentially as reasonably possible.
